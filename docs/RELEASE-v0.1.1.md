**Fast Steam Tools v0.1.1** — установка BetterSteamTools на Windows и исправления работы с загрузчиком.

### Что изменилось

- На Windows при отсутствии Lua-загрузчика FST скачивает **BetterSteamTools v1.0.4** из закреплённого релиза и проверяет SHA-256. Используются трекер `madoiscool/steam-monitor` и его зеркала. Существующие чужие и изменённые вручную DLL сохраняются; нетронутые DLL, установленные FST, могут перейти с прежнего OpenSteamTool на BetterSteamTools.
- Lua зеркалируются в `config/stplug-in` даже без `opensteamtool.toml`. Выбранный основной каталог и дополнительные пути сохраняются; список Lua и удаление учитывают все копии.
- При неудачном восстановлении неполного загрузчика задание останавливается до скачивания из Ryuu.
- Кэш сигнатур проходит полный разбор TOML: пустые, оборванные и синтаксически неверные файлы больше не скрывают проблему совместимости.
- DLL, временно убранные при откате Steam, восстанавливаются в записанную исходную папку, в том числе после перезапуска FST. Смена путей во время операции заблокирована.
- Добавлены проверки Windows-интеграции, сохранён перевод старых записей логов.
- При несовместимости доступен ручной откат Steam с блокировкой самообновления; вернуть обновления можно в окне FST. Откат запрашивает подтверждение.

### Скачать и установить

- **Windows x64:** запустите `FST-Setup.exe`. Установка для текущего пользователя, чекбокс автозапуска, запуск FST по кнопке «Готово».
- **Arch Linux x86_64:**

  ```bash
  sudo pacman -U ./fast-steam-tools-bin-0.1.1-1-x86_64.pkg.tar.zst
  fst
  ```

- **Пользовательская установка Linux:** распакуйте `fst-0.1.1-linux-x86_64.tar.gz` и выполните `bash install.sh` внутри `fst-linux-x64`.
- **Локальная сборка Arch-пакета:** поместите `PKGBUILD` и Linux-архив в одну папку, затем запустите `makepkg -si`. Пакет в AUR не опубликован.
- `SHA256SUMS.txt` содержит контрольные суммы всех приложенных файлов. Проверка Linux: `sha256sum -c SHA256SUMS-linux.txt`.

Linux требует отдельно установленных **SLSsteam + lumalinux** и работающего хранилища Secret Service. [Установка и зависимости](https://github.com/superhe11/FST/blob/main/README.ru.md#arch-linux).

### Проверка и ограничения

Локально прошли 114 офлайн-проверок ядра, 7 Windows-проверок и 32 Linux-проверки. Дополнительно проверены скачивание настоящего ZIP BetterSteamTools в песочницу, его SHA-256 и установка DLL без их выполнения. Проверка сетевого трекера на копиях Steam DLL сборки 1791918634 прошла без локального кэша сигнатур.

**Предварительный выпуск.** Linux проверялся в WSL, не на настоящем Arch со Steam; скачивание и запуск игры на Arch не подтверждены. Совместимость загрузчика с будущими обновлениями Steam не гарантирована. Доступность файлов и лимиты Ryuu определяет сервис. Выпуск не содержит пользовательских ключей, сессий, игр или манифестов; Windows-загрузчик скачивается отдельно во время работы FST.
