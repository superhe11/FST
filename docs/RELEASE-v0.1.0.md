Первый публичный выпуск **Fast Steam Tools** для Windows x64 и нативного Steam на Arch Linux x86_64.

### Скачать и установить

- **Windows:** `FST-Setup.exe`. Чекбокс автозапуска, перезапуск Steam после установки, открытие FST по кнопке «Готово». Нужен уже установленный совместимый Lua-загрузчик.
- **Arch Linux:** `fast-steam-tools-bin-0.1.0-1-x86_64.pkg.tar.zst`:

  ```bash
  sudo pacman -U ./fast-steam-tools-bin-0.1.0-1-x86_64.pkg.tar.zst
  fst
  ```

- **Пользовательская установка Linux:** распакуйте `fst-0.1.0-linux-x86_64.tar.gz` и выполните `bash install.sh` внутри `fst-linux-x64`.
- `PKGBUILD` предназначен для локальной сборки пакета из архива этого релиза; публикации в AUR пока нет.
- `SHA256SUMS.txt` содержит контрольные суммы всех приложенных файлов установки.

Для Linux нужны отдельно установленные **SLSsteam + lumalinux** и системное хранилище Secret Service для сохранения входа. Инструкции и зависимости описаны в [README](https://github.com/superhe11/FST/blob/main/README.ru.md#arch-linux).

### Возможности

Кнопка на странице игры в Steam, подключение Ryuu/Discord с сохранением сессии, трей и автозапуск, RU/EN интерфейс и логи, поиск Lua по AppID/названию и групповое удаление, проверка архивов, резервные копии и откат. На Linux добавлены регистрация SLSsteam и передача ключей в lumalinux.

### Статус проверки

Прошли 37 проверок ядра и 32 Linux-проверки. Проверены сборка Windows, содержимое Windows-установщика, запуск Linux GUI RU/EN, содержимое Arch-пакета и контрольные суммы.

**Linux остаётся экспериментальным:** проверки выполнены в Linux-окружении WSL. Скачивание/запуск игры на настоящем Arch со Steam пока не подтверждены. Доступность файлов и лимиты определяет Ryuu; совместимость загрузчиков зависит от установленной версии Steam.

Установщики не содержат пользовательских ключей, сессий, игр, манифестов или бинарников загрузчиков.
